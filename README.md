# 🎬 Netflix Movies & TV Shows Data Analysis

## 📌 Project Overview

This project performs an exploratory data analysis of Netflix Movies and TV Shows using **Python, Pandas, NumPy, and Matplotlib**.

The goal is to discover useful patterns and trends in Netflix content, including content types, ratings, countries, release years, directors, and titles added over time.

## 🛠️ Technologies Used

* 🐍 Python
* 🐼 Pandas
* 🔢 NumPy
* 📊 Matplotlib

## 📂 Dataset

The dataset contains information about Netflix movies and TV shows.

### Dataset Features

* `show_id` — Unique content ID
* `type` — Movie or TV Show
* `title` — Content title
* `director` — Director name
* `country` — Country of production
* `date_added` — Date added to Netflix
* `release_year` — Original release year
* `rating` — Content rating

Dataset file:

`data/netflix_titles.csv`

## 🔍 Analysis Performed

* Total number of Netflix titles
* Movies vs TV Shows
* Top countries producing Netflix content
* Most common content ratings
* Content distribution by release year
* Netflix titles added over time
* Top directors
* Data cleaning and missing-value analysis
* Statistical analysis using NumPy
* Data visualization using Matplotlib

## 📊 Visualizations

The project generates visualizations for:

* Movies vs TV Shows
* Top 10 countries
* Netflix titles by release year
* Content ratings
* Titles added by year
* Top 10 directors
